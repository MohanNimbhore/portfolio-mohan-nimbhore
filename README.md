# Mohan Nimbhore — Frontend Portfolio

A responsive, frontend-only developer portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code **Live Server** extension.

No backend, build step, or package installation is required.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — styling, responsive layouts, custom project illustrations, and animations
- `script.js` — theme toggle, mobile navigation, scroll progress, and reveal animations
- `assets/Mohan-Nimbhore-Resume.pdf` — downloadable resume

Project cards include direct GitHub and live-demo links. The profile section links to LinkedIn, GitHub, Codolio, and Upwork, and displays the current 200+ LeetCode solved count. The LeetCode profile URL was not present in the resume, so the stat is shown without guessing a profile link.

## Notes
- Platform logos load from Simple Icons / favicon endpoints and therefore require an internet connection.
- The project artwork is made with CSS and HTML because project screenshots were not provided.
- The resume PDF is included in `assets/` and linked through Download Resume buttons.
